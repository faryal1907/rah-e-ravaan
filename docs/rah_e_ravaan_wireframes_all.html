Design notes
Web ↔ mobile parity
What's shared and what's platform-specific
Same account — login once, works on web and Flutter app
AI planner on both; web adds side-by-side itinerary panel
Offline GPS logging + SQLite — mobile (Flutter) only
Parent breadcrumb trail readable on web (no offline needed)
Bookings, payments, enrollment — full feature parity on both
Mapbox tiles shared — React (web) + Flutter (mobile) same source
Background location service and GPS tracking — mobile only
Organizer and admin portals — web only (no mobile view)
